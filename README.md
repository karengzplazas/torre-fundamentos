# 🏙️ La Torre de los Fundamentos Tecnológicos

**De la base a la cima: construyendo los fundamentos para el análisis de datos.**

Una presentación web interactiva que transforma el recorrido de aprendizaje del módulo **Fundamentos Tecnológicos**, del programa Becas para la Vida, en una experiencia visual representada mediante una torre de ocho niveles.

Cada piso simboliza un conocimiento adquirido durante el proceso formativo. A través de una narrativa progresiva y una animación de iluminación, la torre revela cómo diferentes habilidades y herramientas tecnológicas se conectan para construir una base de conocimientos orientada al análisis de datos.

## 🎯 Objetivo del proyecto

Diseñar una presentación web que permita comunicar de manera visual, dinámica y organizada los aprendizajes del módulo, mostrando la relación entre los diferentes fundamentos tecnológicos y su aplicación en situaciones prácticas.

## 🏗️ El concepto: una torre, ocho niveles de conocimiento

La torre representa el crecimiento progresivo del conocimiento. Cada nivel cumple una función dentro de la construcción y se conecta con los demás.

| Nivel | Fundamento tecnológico | Representación |
|---|---|---|
| 1 | Pensamiento crítico y resolución de problemas | Los cimientos |
| 2 | Nube y Google Drive | La infraestructura |
| 3 | Lógica y pensamiento algorítmico | La estructura de acero |
| 4 | HTML y CSS | La arquitectura visual |
| 5 | Python en Google Colab | La automatización |
| 6 | Linux y terminal en Colab | El centro de control |
| 7 | Inteligencia artificial generativa | El taller creativo |
| 8 | Visión integral del analista | El mirador |

## 💡 ¿Qué encontrarás?

- **Narrativa visual progresiva:** recorrido por ocho niveles de aprendizaje.
- **Animación de iluminación:** cada piso se ilumina a medida que avanza la presentación.
- **Navegación interactiva:** controles para avanzar, retroceder y acceder a cada sección.
- **Indicador de progreso:** seguimiento visual del recorrido.
- **Modo pantalla completa:** experiencia de presentación sin distracciones.
- **Ejemplos prácticos:** situaciones cotidianas y ejercicios aplicados a emprendimientos.
- **Diseño adaptable:** ajustes de visualización para diferentes tamaños de pantalla.

## 🚀 Cómo ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Verificar que los archivos de imagen estén en la misma carpeta que `index.html`.
3. Abrir `index.html` en un navegador web.
4. Utilizar los botones de navegación o las flechas del teclado para recorrer la presentación.
5. Presionar la tecla `F` o utilizar el botón de pantalla completa para ampliar la experiencia.
Ver en línea: https://karengzplazas.github.io/torre-fundamentos/

## 🌍 Reflexión final

La tecnología no debe entenderse como un conjunto de herramientas aisladas, sino como un ecosistema de conocimientos que se complementan.

El pensamiento crítico nos permite formular preguntas; la lógica, estructurar soluciones; la programación, automatizar procesos; y las herramientas digitales, ampliar nuestras posibilidades de creación y análisis.

Esta torre representa una base de aprendizaje, no una construcción terminada.

**El conocimiento no tiene un último piso.** 💙
